TZ-10: cap spawn to 1 enemy when Burt level < 5

==========================================================
CONTEXT
==========================================================
На низких уровнях Burt (lvl < 5) толпа волков/гоблинов убивает
сразу. По ТЗ: пока lvl < 5, спавнить только 1 монстра (не стаю).
После lvl 5 — действующая схема.

Единая точка: combat.start_combat принимает enemy_keys (list[str]).
Проще всего обрезать в loop._start_combat (там visible доступен).

Правки в burt/loop.py и tests/.
НЕ ТРОГАТЬ: spawn.py, combat.py.

==========================================================
FIX 1: burt/loop.py — _start_combat
==========================================================
В начале функции (до combat.start_combat):

  def _start_combat(enemy_keys, initiative, hidden, visible):
      # TZ-10: lvl < 5 -> одиночный монстр, не стая.
      if visible.get("level", 1) < 5 and len(enemy_keys) > 1:
          enemy_keys = enemy_keys[:1]
      combat_state = combat.start_combat(enemy_keys, initiative)
      ...

level берётся из visible. Если level отсутствует — default 1 (как
везде в коде).
