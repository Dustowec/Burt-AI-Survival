## Исправление 1: second_roll is None на FAIL-ветке

        # penalty: -1 HP + angry
        ...
    else:
        # plain refusal (second_roll is None или 4-6)
        ...

## Исправление 2: NO_COINS_ROLES — только coins

**Баг:** `if self.role_key in NO_COINS_ROLES and category in ("truth", "polite", "charm"): return {"type": "food"}` — срабатывает ДО `random.choice`, подменяя rumor/item на food.

**Фикс:**
```python
def _pick_bonus(self, category):
    if category == "quest" and self.quest_state != "available":
        return None
    options = BONUS_BY_CATEGORY.get(category)
    if not options:
        return None
    typ, extra = random.choice(options)
    # Только coins заменяется на food для бедных ролей
    if typ == "coins" and self.role_key in NO_COINS_ROLES:
        return {"type": "food"}
    return {"type": typ, **extra}
```

## Исправление 3: Train state machine

**Баг:** `say("train", ...)` уходит в обычную success-ветку, пулы `train_offer/done/used/locked` не используются.

**Фикс:** Добавить state machine до обычной dice-логики:

```python
TRAIN_ROLES = frozenset({"veteran", "cleric", "necromancer", "mage_event"})

# В say():
if category == "train":
    if self.role_key not in TRAIN_ROLES:
        text = self._pick_pool("train", "train_locked")
        return Result(outcome=Outcome.SUCCESS, text=text, bonus=None,
                      hp_change=0, coins_change=0, became_angry=False)
    if self._train_done:
        text = self._pick_pool("train", "train_done")
        return Result(outcome=Outcome.SUCCESS, text=text, bonus=None,
                      hp_change=0, coins_change=0, became_angry=False)
    # Если дошли сюда — обычная success-ветка с bonus skill
```

Новое состояние Session: `self._train_done = False` (boolean, не `bonus_used` — train_done отличается от bonus_used).

## Исправление 4: preacher_event — маппинг curse/nothing/blessing

**Баг:** `_pick_pool("truth", "fail_angry")` → ищет `truth_fail_angry` → `fail_angry` → пусто. Пул `curse/blessing/nothing` не читается.

**Фикс:** Для событий с нестандартным маппингом исходов — отдельный путь:

```python
EVENT_OUTCOME_MAP = {
    "preacher_event": {
        Outcome.FAIL: "curse",
        Outcome.NEUTRAL: "nothing",
        Outcome.SUCCESS: "blessing",
    },
}

# В say():
if self._is_event and self.role_key in EVENT_OUTCOME_MAP:
    pool = EVENT_OUTCOME_MAP[self.role_key].get(outcome, "nothing")
    text = self._pick_pool("event", pool)
    return Result(outcome=outcome, text=text, bonus=None,
                  hp_change=0, coins_change=0, became_angry=False)
```

## Исправление 5: Quest — нужен dice-резолвинг

**Баг:** `return Result(outcome=Outcome.SUCCESS, ...)` — roll игнорируется, квест всегда SUCCESS.

**Фикс:** После определения pool по quest_state — всё равно применять dice-резолвинг для outcome, но текст брать по quest_state:

```python
if category == "quest":
    pool_map = {
        "none": "quest_none",
        "available": "quest_give",
        "in_progress": "quest_already",
    }
    pool = pool_map.get(self.quest_state, "quest_none")
    outcome = self._resolve_outcome(roll, modifier)
    # Текст — по quest_state, а не по outcome
    text = self._pick_pool("quest", pool)
    # Бонус — только если SUCCESS и second_roll 1-3 и not bonus_used
    bonus = None
    if outcome == Outcome.SUCCESS and second_roll is not None and second_roll <= 3 and not self.bonus_used:
        if self.quest_state == "available":
            bonus = self._pick_bonus("quest")
            if bonus is not None:
                self.bonus_used = True
    return Result(outcome=outcome, text=text, bonus=bonus,
                  hp_change=0, coins_change=0, became_angry=False)
```
