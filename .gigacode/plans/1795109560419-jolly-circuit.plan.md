# План изменений: known_issues, валюта, голод, язык UI

## 0. Контекст

Проект BURT v0.7.0. Все 1697 тестов прошли. Аудит выявил 11 расхождений со spec.
Пользователь принял решение:
- Критические и средние расхождения → known_issues
- Голод → known_issues (изменённая механика)
- Валюта → spec дополнена (gold/silver/copper → coin)
- Язык UI → английский (из-за UTF-8), spec дополнить
- Переводы → русский в скобках для ключевых UI-меток

## 1. Создать ТЗ/known_issues.md

Содержимое: список всех расхождений с аудитом, ранжированных по трём уровням.

**Критические:**
1. Логирование (§38-39) — UUID-трассировка, floors, ring buffer, async, JSONL, краш-репорты — НЕ реализовано
2. Валюта — spec v0.7.0 → coin (исправление в процессе)
3. Голод — spec §4 говорит шаги 0/10, код инжектит на каждом шаге eat=False (изменённая механика)

**Средние:**
4. Бандит не требует деньги на 1-м ходу (§23)
5. Цепочки паладина/еретика/убийцы — generic support, конкретные К1-К2-К3 не в коде (§33)
6. Репутация +1/-2 за квесты не реализована (§16)

**Низкого приоритета:**
7. SHOW_SLEEP_TIMER отсутствует в config.py (§31)
8. items.py не содержит таблицу урона оружия (§20)
9. world.py — 2-4 выхода вместо 4 соседа (§17)

## 2. Обновить spec: §31 (конфиг)

Добавить в spec §31:
- `SHOW_SLEEP_TIMER` — убрать (не требуется, по умолчанию True)
- Добавить раздел "Языковые решения": UI на английском из-за проблем с UTF-8 в малых моделях
- Добавить раздел "Валюта": `coin` вместо `gold/silver/copper`, 1 coin = 1 медяк, 1 gold = 1 coin

## 3. Обновить spec: §24 (HP Display)

Добавить примечание: HP-пороги на английском ("fine", "okay", "dangerous, low HP", "critical") — решение из-за UTF-8.

## 4. Обновить spec: §25 (Сенсорный отчёт)

Добавить примечание: секции на английском (`[STATE]`, `[LOCATION]`, `[HANDS]`, `[WALLET]`, `[SKILLS]`) — решение из-за UTF-8.
Добавить правило: ключевые UI-метки с переводом в скобках, например `CHOICE (ВЫБОР)`.

## 5. Обновить spec: §26 (ReAct-тулзы)

Добавить правило: `ВЫБОР (CHOICE)` — формат вызова тулзы.

## 6. Обновить spec: §30 (state.json)

Заменить `gold/silver/copper` на `coin` в примере wallet.
Стартовый кошелёк: `{"coin": 50}` (50 coin = 50 медяков = 5 silver в старой схеме).

## 7. Обновить spec: §35 (Матрица торговли)

Заменить все упоминания "медяк/серебряный/золотой" на "монета/coin".
Убрать "золото" из ивентов находок — заменить на "немного монет".
Цены в spec оставить как числа (в монетах).

## 8. Обновить spec: §4 (Голод)

Добавить раздел "Изменённая механика": инжект на каждом шаге, где eat=False, вместо шагов 0 и 10. Причина: противоречие со статусом "сыт".

## 9. Обновить spec: §37 (Стартовый инжект)

Заменить стартовый кошелёк: 5 silver → 50 coin.
Заменить "золотой" на "монета" в описании денег.
